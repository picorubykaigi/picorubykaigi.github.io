# design/venue-decor

会場装飾用の PicoRubyKaigi 2026 モチーフ柄。`index.html` 1 枚 + `images/` + `fonts/` で完結し、このフォルダの外を参照しない。
人間向けの説明(開き方・案の一覧・色)は `README.md`。以下は編集するときの決めごと。

## 触る前に

- 変更後は必ず描画して確認する。一覧(`index.html`)と原寸(`index.html?capture=a` など)の両方。
  ヘッドレス Chrome なら `--window-size=1507,1177 --screenshot=… "file://…/index.html?capture=c"`。

## レイアウトの決めごと

- 4 案とも `.sheet` は 1120×880px。要素の座標系は 1507×1177px で、`.stage` の `left/top` で見える範囲をずらしている。
  ずらし量は必ず 20 の倍数(穴のドットは 20px 格子。ずれると部品が穴に載らなくなる)。
- c の 4×3 格子は列の中心 x=558/688/818/948、行の中心 y=430/560/690。部品はマスの中心に置く。
- 文字ロゴ(`.prk`)と Ruby(`.ruby` / `.rubym`)の内側にかかる穴のドットは、JS の `knockoutDots` が地色の四角(`.knock`)で 1 個ずつ消す。
  文字の外側で縁に触れるだけのドットは残す(部品が穴の上に載っているのと同じ見え方)。ロゴを動かしても自動で追従するので手で消さない。
- `knockoutDots` は要素の実際の描画位置から計算する。計算が終わるまで `body` を隠し、終わってから `body.ready` を付けて一覧の縮小(`zoom`)をかける。
  縮小を先にかけると位置がずれるので、この順序を崩さない。

## 書き方

- フォントは `fonts/fonts.css`(ローカルの woff2)だけ。Google Fonts など外部を参照しない。
