# 会場装飾用: PicoRubyKaigi 2026 モチーフ柄

PicoRubyKaigi 2026 のモチーフ柄。

## 開き方

- `index.html` をブラウザで開く(Chrome 推奨。文字の縁取りに `-webkit-text-stroke` を使っている)。a / b / c / d の 4 案が縦に並ぶ(0.8 倍。幅 1200px 未満の窓では 0.6 倍)。
- 1 案だけ原寸で見るなら `index.html?capture=c` のように指定する(`a` / `b` / `c` / `d`)。

## 中身

- 4 案とも 1120×880px。要素の座標系は 1507×1177px の中の絶対配置で、`.sheet` を 1120×880 にして中身を `.stage` で 20px 単位にずらしてある(穴のドットとの位置関係を保つため 20 の倍数)。
- `images/` … パーツ・完成品のドット絵、Ruby の LED マーク、ソケット(SVG)。
- `fonts/` … Bitcount Single(文字ロゴ)/ Micro 5(数字・ラベル)/ Jersey 10(吹き出し)。Google Fonts から取ったもので、いずれも SIL Open Font License。

## 案

| | 内容 |
|---|---|
| a | 1 行ロゴ + 2026 + Assemble + パーツ 5 個の列(メインビジュアルの構図) |
| b | 中央にロゴ 4 行、右上にモーター、右下にプラレール |
| c | 組立説明書風の 4×3 格子(パーツ・完成品・吹き出し) |
| d | 上部中央の Ruby の下に中央揃えのロゴ 4 行 |

## 色

- 地: `#eceade`(サイトの --bg)。穴のドット: 20px 格子、`#39352b` 11% と `#1c180e` 14% の重ね
- 文字ロゴ: PicoRuby `#f64b5b`(縁 `#da1d3c`)、Kaigi 白(縁 `#454747`)。墨: `#26242f`、吹き出しの枠: `#34323d`
- 吹き出しの地: `#f6f4ea`(サイトの --card)、名前の札: `#ff96b9`、ソケット: `#f2607a`

## 編集するとき

- 柄は `<template id="proto-a">` などの中。要素はすべて `left/top` の絶対配置(px)。見える範囲を動かすときは `.stage` の `left/top`(20 の倍数)を変える。
- c の 4×3 格子は、列の中心が x=558/688/818/948、行の中心が y=430/560/690。パーツはマスの中心に置く。
- 文字ロゴ(PicoRuby / Kaigi)と Ruby の LED マークの内側にかかる穴のドットは、読み込み時に JS(`knockoutDots`)が地色の四角(`.knock`)で 1 個ずつ覆って消している。文字の外側で縁に触れるだけのドットは残す。ロゴやマークを動かしても自動で追従する。
- ドット消しは各要素の実際の描画位置から計算するので、計算が終わるまで本体を隠し(`body` の `visibility`)、終わってから `body.ready` を付けて一覧の縮小(`zoom`)をかけている。縮小を先にかけると位置がずれる。
