## 試作基板が動きました

最初の試作基板（R1）が手元に届き、ひととおりの機能を確かめました。

![試作基板R1を手に持ったところ。中央上に16×16のLEDマトリクス、中央に赤いミニブレッドボードを貼ってある](/images/blog/adventure-board-dev.jpg)

こちらが試作基板の実物です。手のひらに収まるくらいの大きさで、中央には赤いミニブレッドボードを貼っています。

- **LEDマトリクス** — 16×16の256個が、1ドットずつ明るさを変えて光りました。漢字も表示できます
- **スピーカー** — MMLで書いたメロディが鳴りました。最初は音がざらついていましたが、ファームウェア側を直してきれいに鳴るようになりました
- **ボタン** — 十字キーとA/Bの6個が、短く押しても取りこぼさずに読めます
- **ステータスLED** — プログラムから点けたり消したりできます
- **GROVEコネクタ** — M5StackのCardKB（小さなキーボード）をつないで、キー入力が読めました。もう一方のGROVEでは、基板どうしをつないで通信する準備も進めています
- **ピンソケット** — ブレッドボードで使うピンが、全部つながっていることを確かめました

### コードの書き方も少し変わりました

名前が決まったのに合わせて、基板用のライブラリの名前も `adventure_board` になりました。前回の記事のコードは、今はこう書きます。

```ruby
require 'adventure_board/led_matrix'   # 使う部品を読み込む

matrix = AdventureBoard.matrix         # ライブラリから LED マトリクスを取り出す
matrix.clear
i = 1
while i <= 16
  matrix.set(i, i, 0x60)   # set(x, y, 明るさ)
  matrix.set(i, 1)         # 明るさを省略すると最大の明るさ
  matrix.set(i, 16)
  matrix.set(1, i)
  matrix.set(16, i)
  i += 1
end
matrix.show                # ここでLEDドライバICへ送る
```

LEDマトリクス、ボタン、スピーカーなど、使う部品ごとに読み込んで、`AdventureBoard.matrix` のように取り出して使う形にしました。マイコンのメモリは限られているので、使わないものは読み込まないようにしています。`matrix` がどこから来たのかがコードに書いてあるので、読んで追いかけやすくなっていると思います。

基板には、LEDマトリクスで文字を流す、ボタンでドットを動かす、ライフゲーム、メロディを鳴らす、といったサンプルプログラムも入れておく予定です。

## ブラウザで基板を動かせる「Webコンソール」

もうひとつご紹介したいのが、**Adventure Board Console** です。ブラウザの中でAdventure Boardを動かせる開発環境で、基板が手元になくても、PicoRubyのコードを書いてすぐに結果を見ることができます。

<video src="/images/blog/adventure-board-console-demo.mp4" poster="/images/blog/adventure-board-console-demo.jpg" controls muted playsinline preload="metadata" style="width:100%;height:auto"></video>

動画では、サンプルを選んでLEDマトリクスに文字を流し、ボタンでドットを動かし、その場で書いたコードを実行しています。後半はブレッドボードにLEDをつないで点滅させ、コードを書き換えて点滅を速くしています。

![Webコンソールの画面。左に基板の絵があり、LEDマトリクスに文字が流れている。右にコードの欄と実行ボタン](/images/blog/adventure-board-console-1.jpg)

中身は **PicoRuby.wasm**（WebAssembly版のPicoRuby）です。基板に入るのと同じライブラリや、LEDドライバICと通信するコードを、そのままブラウザで動かしています。**ここで書いたコードは、そのまま基板でも動きます。**

できることをまとめると、こんな感じです。

- **LEDマトリクス・ボタン・スピーカー** — 基板の絵の上のボタンを押したり、キーボードで操作したりできます。音も鳴ります
- **ブレッドボード** — ジャンパ線・抵抗・LED・タクトスイッチを穴に挿して、回路を組めます。電流を計算して、抵抗の数でLEDの明るさが変わります。抵抗を入れ忘れると注意が出ます
- **実機で実行** — 基板をUSBでつなぐと、ボタンひとつで、書いたコードを基板に送って実行できます（ChromeとEdgeで使えます）
- **ライブラリのコードを見る** — `matrix.set` などの中身がどう書かれているか、その場で読めます

特にブレッドボードは、初めて電子工作をする方に使ってほしい機能です。縦に並んだ5つの穴が中でつながっていることが線で見えるので、実物を触る前の練習にもなると思います。

ちなみに、このWebコンソールの画面そのものも、PicoRuby.wasmとFunicular（PicoRuby.wasmのUIフレームワーク）を使って、Rubyで書いています。
